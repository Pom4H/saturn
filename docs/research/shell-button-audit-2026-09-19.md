# Shell: аудит действий, 19 сентября 2026

Участники: основной инженер с проверкой интерфейса в браузере, отдельный агент-дизайнер и отдельный агент в роли product owner. Это экспертная проверка и автоматизированный QA, не пользовательское исследование с внешними респондентами.

Проверяли локальные проекты и настоящий Node/Git/SQLite-сервер с симуляцией 47 устройств. Тестовые изменения, импорт, копирование и перезапуск сервера выполнялись в изолированных профилях и временных хранилищах. Пользовательские проекты не использовались как расходные тестовые данные.

## Исправлено

| Приоритет | Ошибка | Результат |
| --- | --- | --- |
| P1 | «Код», «Файлы», «Свойства» из раздела сигналов меняли скрытые панели | Команды возвращают к сцене и показывают требуемую панель; мобильная кнопка схемы также возвращает к сцене |
| P1 | Создание пустого проекта могло стереть несохранённый серверный черновик | Черновик и его история остаются доступными при возврате к серверному проекту |
| P1 | Ссылка на локальный проект сохраняла `?project=server` и могла загрузить другой проект | Ссылка очищает параметры; открытие исходника по ссылке блокирует автоматическую загрузку сервера |
| P2 | Escape действовал на панели за открытым меню | Закрывает меню; клик снаружи и выбор действия также закрывают его |
| P2 | Низкое окно обрезало команды меню | Ограничение высоты и внутренняя прокрутка сохраняют доступ к последней команде |

| P2 | Файл с расширением `.JSON` попадал в TypeScript-компилятор | JSON-импорт не зависит от регистра расширения |
| P2 | F вписывала только скрытую 2D-схему при работе в 3D | Горячая клавиша использует обработчик кнопки «Вписать» |

| P2 | Состояние кнопок не соответствовало открытому разделу | «Сигналы» имеют активное состояние, скрытые код и свойства не помечены включёнными |
| P3 | Диалог копирования сервера называл его примером | Название и основа соответствуют серверному проекту |

## Проверенные группы действий

- Панели: код, файлы, свойства, сигналы, проекты; прямые переходы и закрытие; полноэкранный режим и мобильная схема.
- Сцена: 2D/3D, масштаб, вписывание, выбор, свойства, переход в исходник, undo/redo, добавление/удаление, соединение, локальная пауза.
- Навигатор: поиск полного пути, пустой результат, очистка, сворачивание, текущий файл, изменённые файлы, закрепление вкладок, история каждого документа.
- Проекты: новый, пустой, копия, дубликат, список и переключатель; копирование многофайлового проекта с открытым README; возврат к серверному черновику.
- Перенос: TS/JSON/HTML-экспорт, ссылка и её открытие, TS-импорт из сигналов, JSON-импорт с верхним регистром расширения.
- Сервер: авторизация, загрузка и обновление настоящей Git-ревизии, защита черновика, SSE, значения, пауза/продолжение исполнения, другая ревизия, обрыв и восстановление соединения.
- Справка: все семь тем, поиск и отсутствие результатов, закрытие и возврат фокуса.
- PWA: открытие настроек и способа установки, темы, проверка обновлений; разрешение и проверочное уведомление — через перехваченные системные API в изолированном тесте. Установка в ОС и реальная выдача разрешений на пользовательском устройстве не выполнялись.

Выполнены `npm run site:check` и полный `npm run site:test:browser`. После последних небольших изменений импорта и подписей повторены typecheck и расширенная матрица `checkInteractions`. Ошибок выполнения в проверяемых сценариях нет. В реальном интерфейсе дополнительно подтверждены подключение к симуляции, возврат из сигналов в код, меню, все темы справки и сохранение дерева при Escape.

Автоматизированные сценарии: `scripts/site-interaction-check.mjs`, `scripts/site-telemetry-check.mjs`, `scripts/site-shell-check.mjs`, `scripts/site-files-check.mjs`, `scripts/site-server-check.mjs`.

## Обратная связь product owner: незавершённые сценарии

1. **Тревоги.** Колокольчик открывает настройки разрешений. Нет центра активных тревог, истории и квитирования в Shell. Следующий шаг — серверный журнал и переход от тревоги к объекту; разрешения браузера должны быть настройкой этого сценария.
2. **Рабочий цикл проекта.** Shell читает серверное исполнение, но pause/resume/commit/publish доступны в отдельном приложении. Нужны явные действия над черновиком, сравнение с исполняемой ревизией и состояние результата с проверкой серверных прав.
3. **Помощь при редактировании Plant.** Автодополнение отключено для многофайловых Plant-проектов. Нужна помощь по DSL, импортам и переходам между файлами на том же контракте, который использует серверный компилятор.

Эти три функции не реализованы текущими исправлениями. Прохождение тестов не означает, что Shell уже завершён как промышленная IDE.
