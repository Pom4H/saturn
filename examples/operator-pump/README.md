# Насосный стенд: инженер и оператор

Один обычный проект `@saturn/core`, который используется для проверяемой демонстрации на лендинге. Откройте каталог `examples/operator-pump` в Saturn как проект; исходник находится в `src/plant.ts`.

Инженер изменяет и публикует проект. Отдельный оператор видит эту же рабочую версию, задаёт скорость `DRIVE`, наблюдает изменение `P-101.flow` и подтверждает предупреждение `low-flow`. При снижении задания до нуля расход модели плавно снижается. Через секунду ниже порога 0.3 появляется предупреждение. Подтверждение не устраняет причину: восстановите задание до 0.72. История сигнала доступна отчёту `pump-flow`.

Это изолированная учебная симуляция с относительными величинами. Соединения описывают отображаемую топологию; модель не является решателем гидравлической сети. Здесь нет драйвера оборудования, сертифицированной защиты или физического PLC. Нулевое задание используется для демонстрации предупреждения, а не аварийного останова реального насоса.

`npm run site:test:release` запускает настоящий сервер, проходит сценарий через интерфейс и проверяет реальные сигналы, команды, подтверждение и рабочую версию. Снимки создаются только после этих проверок. Старый большой учебный объект для этой демонстрации не используется.
