ОДИН ОБЪЕКТ — ОДИН ПРОЕКТ

Не переносите одно и то же изменение между пятью программами.

ВСЕГДА ИЗВЕСТНО, ЧТО РАБОТАЕТ

Версия на ноутбуке инженера и версия на объекте больше не смешиваются.

Saturn отдельно показывает текущую разработку, опубликованную ревизию и то, что реально применено на каждом объекте.

НЕСКОЛЬКО ПРОЕКТОВ И ОБЪЕКТОВ

Один Saturn Server может сопровождать несколько инженерных проектов.

У каждого проекта свой Git-репозиторий и свой жизненный цикл. Один проект может быть развёрнут на нескольких установках.

ОДИН SATURN — РАЗНЫЕ РОЛИ

Инженер проектирует. Оператор работает. Сервер хранит историю.

Это не три независимых продукта. Они используют один проект и одни идентификаторы оборудования.

Инженер

Проектирует объект, проверяет изменения и выпускает ревизии.

Оператор

Видит HMI, сигналы, аварии и доступные команды.

Saturn Server

Исполняет runtime, пишет историю, формирует отчёты и обслуживает несколько проектов.

Руководитель

Видит состояние установок, версии и историю изменений.

КАК ЭТО УСТРОЕНО

Открытый проект. Обычный Git. Автономная работа на объекте.

Под капотом Saturn использует TypeScript, Git, SQLite и открытые расширения. Но инженеру не нужно становиться web-разработчиком, чтобы пользоваться системой.
