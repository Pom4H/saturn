Редактируйте проект в Saturn IDE.

Это запущенная IDE: схема, код, файлы и инструменты проекта работают прямо внутри страницы.

Откройте рабочий runtime.

Это реальный браузерный runtime Saturn с симуляцией, телеметрией, управлением, алармами и отчётами.

Оба блока выше — работающие интерфейсы Saturn, а не изображения. Runtime использует встроенную демонстрационную модель без подключения к оборудованию.

Знайте, какая версия
работает на объекте.

Можно продолжать разработку, пока runtime исполняет применённую версию. Публикация и применение — отдельные состояния.

  1. 01 / SOURCE

    Черновик

    Редактируйте схему и обычные файлы проекта. Git сохраняет историю изменений.

  2. 02 / BUILD

    Проверка

    Сборка проверяет проект и создаёт артефакт с привязкой к исходной версии.

  3. 03 / PUBLISHED

    Публикация

    Выберите подготовленную сборку для конкретного окружения.

  4. 04 / APPLIED

    Рабочая версия

    Видно, какую сборку фактически исполняет runtime на объекте.

Ошибка в новом черновике не заменяет работающую конфигурацию.Как это устроено ↗
